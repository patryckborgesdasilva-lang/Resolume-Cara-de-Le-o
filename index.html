Holyrics

  • No Holyrics: Arquivo → Configurações → API Server. Ative, anote a porta e crie um token em “gerenciar permissões”.
  • Aqui: botão Holyrics na barra de cima → preencha IP, porta e token → Testar conexão.
  • Holyrics ao vivo (clique num +): mostra o slide que está no ar no Holyrics com o seu visual, por cima dos seus fundos. As setas/passador avançam o Holyrics.
  • Importar: traz as músicas do culto (ou busca) como clipes de texto, e os vídeos/imagens da pasta de mídia do Holyrics.
  • Para a conexão funcionar sempre, abra o programa pelo Iniciar-Windows.bat (ele liga a “ponte” local).

NDI (câmeras pela rede)

  • Instale o NDI Tools (gratuito) e abra o NDI Webcam Input. Escolha nele a câmera NDI — ela vira uma “webcam” no computador.
  • Aqui: clique num + → Câmera NDI. O programa escolhe a fonte NDI sozinho (ou troque em “Dispositivo”).
  • O Holyrics também tem saída NDI: dá para trazer a tela inteira dele (com os fundos) do mesmo jeito.

OBS (entrada)

  • No OBS: Ferramentas → Configurações do servidor WebSocket → ative. Aqui: botão OBS → senha → Conectar.
  • Câmera do OBS ao vivo: + → OBS — câmera virtual. No OBS 30+, na engrenagem da câmera virtual escolha “Fonte” → placa de captura.
  • Qualquer cena/fonte do OBS: + → Cena ou fonte do OBS (por imagens, até 15 por segundo).

Saídas

  • HDMI: botão Saídas → abrir a janela do projetor → enviar para a tela do projetor → dois cliques para tela cheia.
  • OBS: botão Saídas → copie o endereço → no OBS, adicione uma fonte Navegador. Há um endereço com o programa completo e outro só com as letras (fundo transparente).

Como funciona

  • Camadas: a de cima fica por cima. Ex.: Fundo (vídeo) → Mídia (logo/avisos) → Letras.
  • Clique num clipe para colocá-lo no ar na sua camada. Clique com o botão direito (ou no ✎) para só editar.
  • Arraste vídeos e imagens do computador direto para as células. Arraste clipes entre células para reorganizar.
  • No clipe de texto, cada linha em branco cria um novo slide.
  • Tudo é salvo automaticamente neste navegador (inclusive os vídeos).
